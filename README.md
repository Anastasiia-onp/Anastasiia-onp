## Как я работаю

**Сначала данные, потом вывод.** Расчёт показывается целиком: формула, источник
каждой цифры, контрольные суммы. Вывод без расчёта — это мнение, а не анализ.

**Ничего не додумываю.** Если данных нет, так и написано: «данных нет».
Допущение всегда помечено как допущение и отделено от факта.

**Исходные данные неприкосновенны.** Любая обработка — в новый файл.
Сохранность исходника важнее удобства работы.

**Результат — управленческое решение.** Отчёт, по которому нельзя принять решение,
работу не закончил.
